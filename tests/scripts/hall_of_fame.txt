# The Hall of Fame: the credits sequence as the Champion's room starts it (the Hall of Fame screen with the party, the
# save, the dial message). Passes if the game gets back to the overworld.
#
#   tools/docker/desktop.sh test tests/scripts/hall_of_fame.txt --from turtwig
