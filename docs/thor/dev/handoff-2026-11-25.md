# Handoff: the whole project, 2026-11-25

A snapshot of everything: what the project is, where each piece stands against its goals, what is in flight right
now, and how to pick it up on another machine. It comes with a bundle, `pokemon-thor-handoff-2026-11-25.zip`, whose
layout is described at the end. The detailed plans stay authoritative for their areas (list at the end); this file
ties them together and brings `plan.md` (last rewritten 2026-11-17) up to date.

---

## 1. The project in one page

**What it is.** A fork of the PC/Android ports of the Pokémon Platinum and HeartGold/SoulSilver decompilations
(upstream: `SilasMayes/pokeplatinum-thor`, `SilasMayes/pokeheartgold`, libntr, port-common), aimed at the owner's
handhelds: AYN Thor (dual-screen Android) and Retroid Pocket Duo. The player supplies their own ROMs; nothing from a
ROM is ever committed.

**The two apps**

| App | Game | Package | Repo / working branch |
|---|---|---|---|
| **Eterna** | Platinum (+ Renegade Platinum, Following Renegade Platinum) | `app.eterna` | `teton-dev/pokeplatinum-thor-ls`, `gen5-battles` |
| **Goldenrod** | HeartGold / SoulSilver (+ Sacred Gold / Storm Silver) | `app.goldenrod` (dev flavour `app.goldenrod.dev`) | `teton-dev/pokeheartgold-thor-ls`, `thor-android` |

Java namespace is `org.pokeplatinum.port` in both (libntr's JNI names need it).

**The headline feature: Gen 5 battles.** With *Settings > Battles > Gen 5 battles* on, every battle the game sets up
runs in Black 2/White 2's real battle engine and battle view, compiled from the
[pokebw2](https://github.com/fuddlesworth/pokebw2) decompilation (GPLv3). The `FieldBattleDTO` is converted to BW2's
`BtlSetup` and the results written back (`gen5/`, shared by both games: HGSS's `gen5` is a symlink to Platinum's).
The player imports their own **Black 2 or White 2 (USA)** ROM in Settings; BW2's files, sound effects and cries come
from it at runtime.

**Roadmap (owner's order)**: Gen 5 battles in Platinum → HGSS support → Renegade Platinum → enhanced graphics.
The owner pulled enhanced graphics forward on 2026-11-23, so it is now being worked on in parallel.

**Standing decisions**
- Fork-only because of the GPL (pokebw2); ask upstream's developer before proposing any Gen 5 code there.
- pokebw2 is never changed: the port's shims and patches live in `gen5/` (`gen5/patches/*.patch`).
- Vanilla Platinum first; trainers keep their own game's AI levels.
- Out of scope: following Pokémon *in BW2's engine*, visible wild Pokémon, BW2 Phenomena, name capitalisation, Pokéwalker.
- Pal Park should work (via *Settings > GBA slot*); the Battle Frontier runs in Gen 5 with its own music/sprites;
  Frontier Brains get BW2's World Tournament light-pools arena (bg 19, alt 1).
- Post-catch screen order: BW2's nickname question first, then the Pokédex entry (settled; don't reopen).
- Upstream PRs only when the work is fully working and debugged.
- Enhanced graphics: every effect its own off-by-default setting; light on the Thor's GPU; never filter pixel art
  (AA stays off; a 4–6x internal resolution replaces it).
- Commits as the owner, ending `Co-Authored-By: Claude …`; no session links in commits or PRs.

## 6. Building and testing

**Layout expected by the builds** (siblings): `~/pokeplatinum-thor-ls`, `~/pokeheartgold-thor-ls`, `~/pokebw2`
(at `2c3961614d`, unmodified), `~/thor-dev` (ROMs, fixtures, data folders, APKs).

- **Desktop (Docker):** `tools/docker/desktop.sh build`, then `start` (VNC at `vnc://localhost:5900`) or
  `test tests/scripts/<x>.txt --from <fixture>`. `desktop.sh test` **does not rebuild**: run `build` first. Several
  sessions share the container name `pokeplatinum-test`: don't run two at once. Eterna's container is x86 under
  Rosetta; Goldenrod's runs arm64. Details: `desktop-docker.md`, `tests/README.md`.
- **Key tests:** `new_game.txt --keep before-starter`, `first_battle.txt --from before-starter`,
  `gen5_battle.txt --from turtwig`; the Gen 5 suites `gen5_*.txt`; enhanced graphics `enhanced_*.txt` with
  `POKEPLATINUM_ENHANCED_HOUR`. Grep the log for `battle ended (BW2's result N` (1 won, 0 lost): a test that doesn't
  check can "pass" a lost battle.
- **Data folders** (`~/thor-dev/desktop`, `desktop-hg`, `desktop-renegade`, `desktop-following`, `desktop-sg`): the
  first start extracts the ROM there (link the ROM in: `ln -s ../PKMNPLAT.nds ~/thor-dev/desktop/`) and Settings >
  Battles imports the BW2 ROM into `gen5/`. The bundle has only their `.ini` files; everything else regenerates.
  Following Renegade: `DATA=~/thor-dev/desktop-following tools/docker/desktop.sh test …` (fixtures `fr-before-starter`, `fr-turtwig`).
- **APKs, natively on macOS** (no Docker since 2026-11-20): Homebrew `openjdk@17`, `meson`, `ninja`, `cmake`,
  `nasm`, `pkgconf`, `bison`, `python@3.12`; Android SDK (platforms;android-35, build-tools;34.0.0), NDK r27c
  (`~/Library/Android/sdk/ndk/27.2.12479018`), Gradle 8.10.2 in `~/Library/Android`; for Eterna also the Arm GNU
  15.3.rel2 toolchain at `~/Library/Android/arm-gnu/toolchain/bin` and `POKEBW2=~/pokebw2`.
  Goldenrod: `tools/docker/desktop.sh apk`. Eterna: `rm -rf build_android`, then `./tools/android/build_apk.sh` with
  the same environment plus `VERSION_CODE`. ~10 min.
- **Python ≥ 3.11** is needed by the Gen 5 header generators (system Python 3.9 is too old).

## 7. Gotchas worth knowing before touching anything

- **Concurrent sessions**: other sessions have edited the same files (`libntr.wrap`'s `diff_files` line has been
  overwritten before; `gen5-battles.md`, `gui_settings.cpp`, `src/meson.build`). Check `git diff` for hunks that
  aren't yours before committing; commit your own with `git hash-object -w` + `git update-index --cacheinfo`.
- **64-bit layout bugs** are the recurring crash family, especially in HGSS's decomp: `u32` offsets or pointers,
  `unk[0x..]` reads of structs holding pointers, DS-sized arenas (the Frontier particle heap), DS divisions that
  don't trap. Heap "free size 0 with room left" means corruption, not exhaustion.
- **BW2's engine**: first pad press on a menu only shows the cursor (tests touch); after a battle reset the master
  brightness; screens run outside a battle need its fonts; `BtlvEffect_CalcGaugeHP` takes HP *left*.
- **HGSS ≠ Platinum APIs** (`GetMonData` vs `Pokemon_GetValue`, etc.); `CreateMon(…, OT_ID_PLAYER_ID, …)` gives OT 0
  and BW2 treats the Pokémon as traded: use `OT_ID_PRESET`.
- The desktop build can't reach HGSS's Pokégear; check it on a device.
- macOS BSD `sed` lacks `\n` in replacements: use Python for edits. The Linux NDK can't unzip on the Mac's
  case-insensitive disk.
- Never commit ROMs, saves, extracted files, or anything from a BW2 ROM.

**Restore**: unzip into the home folder so `repos/*` become `~/pokeplatinum-thor-ls`, `~/pokeheartgold-thor-ls`,
`~/pokebw2` (siblings matter: `-Dpokebw2=../pokebw2` and the `gen5` symlink), move `roms/`, `hack-patches/`,
`fixtures/`, `apks/` into `~/thor-dev` (`apks` as `apk`), and the `data-config/<folder>/*.ini` files into
`~/thor-dev/<folder>/`. Then in each repo `git worktree prune` (the recorded worktree paths are this Mac's).

**No symlinks in the zip** (7-Zip on Windows refuses links that point up a folder): Goldenrod's `gen5` is a symlink to
`../pokeplatinum-thor-ls/gen5` in git, and the zip holds a copy of that folder instead, so `git status` there shows
`gen5` as changed. On macOS or Linux, put the link back: `rm -rf gen5 && git checkout -- gen5` in Goldenrod's repo.
On Windows the copy builds as it is, but edits made there don't reach Eterna's `gen5`: make shared Gen 5 changes in
Eterna's copy and copy them over (or enable symlinks: Developer Mode and `git config core.symlinks true`, then the
same checkout). meson's own `subprojects/meson-1.12.0/test cases/` (it has such links) is left out; the build doesn't
use it. The longest path in the zip is 190 characters: extract to a short folder (e.g. `C:\thor`) on Windows.

**Left out on purpose** (regenerable, superseded or noise): `build_linux/`, `build_android/`, Android Gradle outputs
(`android/app/build`, `.gradle`, generated `assets`/`jniLibs`/SDL java), `tools/metroskrew` and the linuxdeploy
AppImage (downloaded tools), `.claude/` worktrees; in `~/thor-dev`: every `test-run*`, `test-shots`, `shots`,
`scratch`, `clip-compare`, `gen5-probe`, `anim-base`, the build copies `apk-build`, `apk-combined`, the `duo-pacing`
worktree (its branch is in `.git`) and its `-trash-`/`-base` copies, `pacing-base-0125`, `verify-series-0125`, older
APKs, all `*.log` / `*.txt` dumps, the extracted ROM data inside the `desktop*` folders, the downloaded Android
toolchains (`android-download`, `ndk-download`: the JDK there is Linux x86-64, useless on macOS), and `hg-engine-main`
(a non-git download of BluRosie's public hg-engine, reference only).
